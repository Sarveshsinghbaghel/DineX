# Branching Strategy

## Branch Prefixes

- `codex/feature-*` for feature work
- `codex/fix-*` for defect work
- `codex/chore-*` for repository and tooling work

## Rules

1. Branch from the active integration branch.
2. Keep pull requests focused on one architectural concern where possible.
3. Avoid mixing repo foundation changes with unrelated business feature work.
